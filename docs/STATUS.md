## 使用边界

动态工具仍是限时、版本绑定的 Windows 探针。必填客户端路径，并核验 PID 对应路径、EXE SHA-256 和候选函数字节。离线校验、打包及隐私清理不会启动或附加客户端。

媒体代码只提供后续研究入口。静态字段识别不等于动态接收成功；嵌入缩略图也不能当作完整原图。
