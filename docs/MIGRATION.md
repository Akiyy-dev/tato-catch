# 公开源码范围

研究代码已整理为独立的源码探针工具包。原始样本、工具、反编译工程、运行记录及迁移备份仅留在本地被忽略的目录，不作为公开仓库或发布包的输入。

公开文件包括原创研究结论、探针源码、静态分析脚本、构建检查、合成测试和使用文档。历史进程号、精确实验时间、运行基址、机器路径及原始消息实验报告不随源码发布。

客户端路径由 `--target-exe` 提供；运行器校验文件 SHA-256 和 PID 路径后，将路径写入临时 JS，结束时清理。Ghidra 路径通过运行参数提供。路径可配置不会放宽版本和代码字节检查。

本地 JSON、CSV、日志、输出文本及历史 fixtures 均被 Git 忽略。发布校验额外拒绝机器绝对路径和原始 fixtures；构建直接复用该检查。新增公开数据应采用合成内容，并接受人工隐私审查。

历史发布已撤回。清理后的 Git 历史不应与旧副本合并，以免重新引入被移除的记录。
